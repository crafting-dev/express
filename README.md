## Quick Start

Download Crafting CLI:

```sh
curl -sSL https://sandboxes.cloud/sh/install-cli | bash
```

Alternatively, you can download using the [direct links](docs/Download.md).

Launch the _Crafting Express Edition_ using a single command:

```sh
cs express start
```

It will guide you to:
- Sign-up a login;
- Create Docker volumes for persisted states and data;
- Create Docker container to run the _Crafting Express Edition_;
- Final instructions to access _Crafting Express Edition_ via Web UI and CLI.

For more details, checkout [Documents](https://docs.sandboxes.cloud).
Please [reach out](https://crafting.dev/contact) to deploy the true Enterprise scale edition
for your organization.
