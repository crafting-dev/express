# Crafting Download Links

## CLI

- For Mac OS Apple Silicon (ARM64)

  ```sh
  curl -sSfL https://storage.googleapis.com/cloud-sandboxes/cs/2.3.2-22034e2/cs-darwin-arm64.tar.gz | sudo tar -C /usr/local/bin -xz
  ```

- For Mac OS Intel

  ```sh
  curl -sSfL https://storage.googleapis.com/cloud-sandboxes/cs/2.3.2-22034e2/cs-darwin-amd64.tar.gz | sudo tar -C /usr/local/bin -xz
  ```

- For Linux x86_64

  ```sh
  curl -sSfL https://storage.googleapis.com/cloud-sandboxes/cs/2.3.2-22034e2/cs-linux-amd64.tar.gz | sudo tar -C /usr/local/bin -xz
  ```

- For Linux ARM64

  ```sh
  curl -sSfL https://storage.googleapis.com/cloud-sandboxes/cs/2.3.2-22034e2/cs-linux-arm64.tar.gz | sudo tar -C /usr/local/bin -xz
  ```
